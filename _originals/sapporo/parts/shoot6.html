장소: 조잔케이 유라쿠소안 출발 → 레이크라인 → 아사리댐 루프교 → 오타루 마사즈시 본점
정보: 통행료 0엔, 약 1시간, 11시 오마카세 예약
구조: 훅(단풍 터널 0~2초) → 전개(커브·표지판) → 하이라이트(아사리댐 루프교 공개) → 엔딩(첫 접시 → 터널로 루프), 20~40초
소스: 02_베스트 폴더 10/18 파일. 가로 4K는 9:16으로 크롭.
버전 2개: ① 유튜브 쇼츠용 자체 BGM 버전 ② 릴스용 무BGM 버전(음악은 앱에서 붙임)
필수: 여친 얼굴 나온 컷 전부 제외(룸미러·창문 반사 포함), 모르는 사람 얼굴 블러, 자막은 반말·짧게.

장소: 마사즈시 본점 → 메르헨 교차로 증기시계 → 오르골당 → 르타오 본점 → 기타이치 홀 → 가마에이 → 류게츠 → 다이쇼 유리관 → 아사쿠사바시
정보: 판롤 264엔, 운하 크루즈 낮 1,800엔, 운하 관광주차장 최대 1,000엔
구조: 훅(노을 타임랩스 마지막 1초) → 전개(장소마다 이름+가격 1줄) → 하이라이트(기타이치 홀 램프 공개) → 엔딩(노을 → 첫 장면 루프), 20~40초
소스: 02_베스트 폴더 10/18 파일
버전 2개: ① 유튜브 쇼츠용 자체 BGM ② 릴스용 무BGM
필수: 여친 얼굴 제외(실루엣·뒷모습만), 모르는 사람 얼굴 블러, 가게 안은 촬영 OK였던 곳만, 확인 안 된 가격은 자막에 넣지 말 것.

롱폼 · 로드트립 브이로그
[롱폼 편집 요청]

챕터: 콜드오픈 → 인트로(차 안 토킹) → Ch1 도착·라멘·렌트 → Ch2 시코쓰호 → Ch3 료칸의 밤 → Ch4 레이크라인 → Ch5 오타루 → Ch6 스스키노 와규 → Ch7 비 오는 삿포로 → Ch8 귀국·경비 정산
